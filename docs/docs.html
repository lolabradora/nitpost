PaneParcel docs

Annotate a web page and send selected notes to an open local Codex CLI or Claude Code conversation. You pick the project and destination in Chrome. Rex is optional.

Each note includes your comment, its kind, the full source URL and the viewport size. Element and group notes identify what you picked. An area note records the region you marked. You can leave out the excerpt or screenshot and attach a reference image of the result you want.

PaneParcel has two parts: a Chrome extension that starts from its toolbar icon, and a signed, Apple-notarized companion that runs on Apple Silicon Macs and delivers notes to your agent.

Install

You need an Apple Silicon Mac, Google Chrome and the CLI for your chosen agent.

1. Run the installer

From the PaneParcel checkout: Open a terminal where your agent CLIs are on PATH.

curl -fsSL https://github.com/lolabradora/paneparcel/releases/download/v0.3.0-beta.2/install.sh | /bin/sh

The installer verifies the bundled archive against a pinned SHA-256, installs the companion and the extension under ~/Library/Application Support/PaneParcel, and registers the companion for the current Google Chrome user.

2. Approve the extension in Chrome

Open chrome://extensions, enable Developer mode and click Load unpacked. Press ⌘⇧G in the folder dialog, enter the folder below, and confirm.

~/Library/Application Support/PaneParcel/extension

A managed browser can require administrator approval.

3. Pin PaneParcel

Allow site access on the pages you want to annotate. Pin PaneParcel in the Chrome toolbar and click its icon to start picking. For local HTML files, enable Allow access to file URLs in the extension details.

Annotate a page

  1. Click the PaneParcel icon or use Option + Shift + P. Pick an element, mark an area or group several elements.
  2. Write your note and save it. Save as many notes as you need.
  3. Review the batch and choose a project and conversation. Press Send to deliver directly, or Copy for agent to paste text feedback yourself. Chrome stays in front.

Drafts belong to the exact page URL. When a send has no receipt, check the original conversation before choosing whether to mark the notes as received, keep them as drafts or retry. Use the picker in the top-level document.

Keyboard

Activate PaneParcel from the Chrome toolbar, select a focusable element with Enter, save with ⌘/Ctrl + Enter, or cancel with Esc.

Choose a conversation

Choose Project, then Conversation. Both are visible before you press Send. The short thread ID or the Rex tab and pane label tells conversations in the same folder apart. Your selection follows you to the next site, so feedback for one project can stay in one thread.

Refresh the picker after opening, closing or switching sessions. With no saved choice, a single active conversation is preselected. The last 12 project folders are available across sites.

Rex Best integrated

PaneParcel is at its best with Rex. Your panes appear in the picker by tab and pane label, and notes land in the one you choose. Rex is also the only route that can start a new agent session for you.

  • Any agent, one place. Send to a Codex or Claude Code pane with an empty, ready prompt.
  • New sessions from Chrome. Start a Codex or Claude Code session in the selected folder, with your notes as its first prompt.

What PaneParcel does not do

It does not resume or fork sessions, edit history, approve agent prompts, start a daemon for discovery, or silently fall back from one delivery mechanism to another. The picker has no routes to cloud, SSH-only or other-account sessions.

What your agent receives

Every batch labels the Source page, the Selected element and the User note, so the agent can use them immediately.

Source page
The full page URL, including any query and fragment.
User note
Your note, exactly as you wrote it, and whether it is a change request or a question.
Selector
A CSS selector for the element you clicked. A unique ID where one exists, otherwise its structural path.
Text
A short excerpt of the element’s text.
Viewport
The size of the browser viewport when you picked the element.
Screenshot
A cropped image of the selected element, saved as a local file the agent can open.

Optional agent skill

The optional PaneParcel skill helps your agent tell a bug in your own page from a design reference on another site, and apply the feedback to the project open in the conversation. Installing and sending work without it.

Install it from GitHub in the project where you use your agent.

npx skills add lolabradora/paneparcel --skill paneparcel

Choose Codex or Claude Code when prompted. Add -g to make it available across projects. Start a fresh agent session to pick up the skill.

The Apple Silicon package also includes the skill: run the installer with --skill codex or --skill claude.

Notes and privacy

PaneParcel activates when you click its toolbar icon or press its shortcut. Drafts, their screenshots and reference images, recent folders, destination preferences and a record of the last send from each page are stored in Chrome’s local extension storage. A draft stays until you remove it or a send removes it. A send with no receipt keeps its notes until you mark them as received. There is no developer-operated account, analytics service or cloud backend.

Sending shares the full URL including query and fragment, the selected element context, your comments and the screenshot paths with the chosen agent, which uses its own configured model provider. When you send, the companion writes each image to a private cache folder on your Mac. It deletes files older than seven days whenever Chrome next contacts it, and uninstalling the companion removes the folder.

Some terminal routes and new-session prompts use command arguments that are visible to local process inspection. Choose pages and destinations accordingly.

Update or uninstall

Update

Run the installer for the next release, then click Reload on the extension at chrome://extensions and refresh any open annotated pages. Saved notes, recent projects and destinations stay with the same Chrome extension entry. Run the installer again after moving a CLI.

If Chrome loads the extension from a development checkout, pass that folder explicitly.

sh install.sh --extension-dir "/absolute/path/to/your/existing/extension"

Uninstall

This removes the companion and its registration with Chrome. The extension and its local notes remain available.

"$HOME/Library/Application Support/PaneParcel/paneparcel" register uninstall

For complete removal, remove PaneParcel in Chrome when you are finished with its drafts, then delete the installed PaneParcel folder. The installer never edits the Chrome profile database, agent configuration or transcripts.
