Install the beta.

The signed, Apple-notarized Rust companion runs on Apple Silicon Macs. You’ll need Google Chrome and the CLI for your chosen agent.

The setup below uses Chrome’s unpacked extension option.

GitHub beta release

  1. Run the installer

    From the PaneParcel checkout: Open a terminal where your agent CLI is on PATH. The installer checks the archive’s SHA-256, installs the companion and extension, and registers the companion with Chrome.

    curl -fsSL https://github.com/lolabradora/paneparcel/releases/download/v0.3.0-beta.2/install.sh | /bin/sh

  2. Approve the extension in Chrome

    Open chrome://extensions, enable Developer mode, and click Load unpacked. Press ⌘⇧G, enter the folder below, and confirm.

    ~/Library/Application Support/PaneParcel/extension

  3. Pin PaneParcel and pick an element

    Allow site access on the pages you want to annotate. Use Copy for agent to copy feedback as text even without a connected session. Pin PaneParcel from Chrome’s Extensions menu, open a page, and click the toolbar icon. For local HTML, enable Allow access to file URLs in the extension details.

Optional agent skill.

Using a page as a design reference? The optional PaneParcel skill helps Codex and Claude Code apply your notes to the project you’re working on.

Install it from GitHub in the project where you use your agent.

npx skills add lolabradora/paneparcel --skill paneparcel
