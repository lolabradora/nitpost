# PaneParcel pre-launch feedback research

November 25, 2026 · Apple Silicon and Chrome release candidate

## Release decision

Prioritize getting a first note into the intended conversation, even when a local integration is unavailable. Ship a clear connection state and a **Copy for agent** action before expanding capture modes. Treat this as a product recommendation. Public issues provide firsthand accounts from other products, official documentation shows available workflows, and the local audit identifies where those workflows intersect with PaneParcel. None of these sources establishes how often PaneParcel users will request a feature.

## What people have asked for or used

| Situation | Evidence | Implication for PaneParcel |
| --- | --- | --- |
| Notes appear saved but the agent receives nothing | One user reported roughly 30 minutes spent on setup. Another reported passing checks with zero annotations visible to the agent. [Agentation issue 173](https://github.com/benjitaylor/agentation/issues/173) | Explain separately whether Chrome can reach the companion, whether it found an eligible conversation, and what a submission confirmed. Offer a retry that refreshes discovery without sending. |
| Taking feedback to a different agent | Agentation ships an independent copy action. A Chrome annotator documents copying structured Markdown into agents including Copilot. A user of Agentation in a vanilla PHP app specifically valued sending directly once connected. [Agentation features](https://www.agentation.com/features#toolbar-controls) · [Visual Annotator](https://github.com/wernerstrauch/visual-annotator) · [User account](https://github.com/benjitaylor/agentation/discussions/166) | Keep Send primary. Copy the page URL, note kind, user note, selector, excerpt and viewport even with no helper installed. Keep the draft. Text-only clipboard output should make its image scope clear. |
| Showing the desired result | Two participants described wanting to paste or attach reference images. PaneParcel’s automatic crop shows the current element. [Agentation issue 120](https://github.com/benjitaylor/agentation/issues/120) | First beta experiment: paste one reference image alongside the captured element and distinguish them in the message. Ask whether annotating the example on a second site already solves the task. |
| Capturing a dropdown before it closes | Clicking an annotation tool dismissed the menu the author wanted to describe. Another user reported an editor shortcut conflict. [Dropdown report](https://github.com/benjitaylor/agentation/issues/193) · [Editor conflict](https://github.com/benjitaylor/agentation/issues/190) | Test activation over an open dropdown. Try a discoverable Chrome extension shortcut before introducing animation freezing or page-wide key handlers. |
| Describing space or a relationship | A user asked to select several separated elements with one comment. Agentation supports multi-select and area selection; Vercel documents drag-to-capture regions. [User request](https://github.com/benjitaylor/agentation/issues/175) · [Agentation](https://github.com/benjitaylor/agentation) · [Vercel Comments](https://vercel.com/docs/comments/using-comments#add-screenshots-to-a-comment) | Test a spacing task such as “reduce this gap.” A region can carry coordinates and a crop without fabricating a CSS selector. Grouped elements are a distinct feature. |
| Controlling what leaves the page | Marker.io documents masking sensitive data before sharing screenshots. That is a product precedent. [Marker.io masking](https://help.marker.io/en/articles/9657817-sensitive-data-masking) | A smaller launch option is to preview the crop and omit it per note. Test with an authenticated dashboard containing a customer email. |

## Candidate audit and beta checks

- The candidate already captures an element crop, supports Change and Question, batches notes on each URL, remembers a chosen destination between sites, and allows editing or removing notes. A saved destination can span sites while drafts remain page-specific. Review currently exposes an attachment indicator. [Picker and review](../extension/content.js) · [Storage and capture](../extension/background.js)
- Claude inbox submission has no end-to-end receipt. Preserve drafts and distinguish a prior attempt from a fresh draft when reopening. Give the user the destination and time before they repeat an uncertain send. A user report from another tool motivates testing two SPA routes, offline capture and reconnection. [Claude delivery](../companion/src/agents.rs) · [Agentation issue 228](https://github.com/benjitaylor/agentation/issues/228)
- Align release copy with the candidate. The manifest summary still implies that Rex is required. The privacy policy describes seven-day deletion, while the companion prunes files older than seven days when processing another batch with images. [Manifest](../extension/manifest.json) · [Privacy wording](../PRIVACY.md) · [Cleanup implementation](../companion/src/main.rs)

Run a small observed beta with five developers across Codex and Claude Code. On a clean profile, have each send one change from their own app and one reference from a different site to the same project. Then close the destination before sending a third note. Record time to the first note visibly received in the intended session, whether the participant needed help, whether they could recover their draft, and whether anyone sent twice. Separately ask each participant to show the desired result using a reference image and to comment on an open dropdown. Count observed friction before choosing the next capture feature. Proposed launch criteria: every draft survives a failed send, every successful test reaches the chosen thread, and at least four of five participants finish unaided. These are acceptance targets for a pilot.

Defer team inboxes, ticketing integrations and continuous recording until beta users demonstrate a workflow that needs them. Direct local delivery and portable feedback cover the initial promise with less setup.
