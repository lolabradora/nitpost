# PaneParcel privacy

PaneParcel is a local annotation tool for developers. It activates when you click its toolbar icon. Selecting a page element records its CSS selector, a short text excerpt, the page URL and viewport dimensions alongside your comment. File URLs can include your local folder and file names.

Drafts, recent folders and destination preferences are stored in Chrome’s local extension storage. The native companion discovers supported local coding-agent sessions on your Mac and returns destination information to the extension. PaneParcel operates without a developer-operated account, analytics service or cloud backend.

When you send a batch, the selected agent receives the annotations, including the full URL and any query string. That agent may send the content to its configured model provider under its own settings. Some local delivery routes use process arguments. Choose pages and destinations accordingly.

Remove individual notes in the review panel. Remove the extension to clear its local storage. The companion can be uninstalled separately using the command in the README. For privacy questions, open an issue at https://github.com/lolabradora/paneparcel/issues without posting private annotations.
