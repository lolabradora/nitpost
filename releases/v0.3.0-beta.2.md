## What’s new

- Mark an element, several related elements, or an area of the page. Ask a question or request a change.
- Preview the screenshot, omit its image or text excerpt, and attach a reference image to show what you want.
- Use **Copy for agent** to paste text feedback anywhere, even when a local agent is unavailable. Drafts stay in Chrome.
- Send directly to an eligible Codex or Claude Code conversation. Your destination follows you across sites. If the helper cannot confirm delivery, check the original conversation before retrying.
- Open the picker with **Option + Shift + P** on macOS when the shortcut is available. Chrome lets you change it at `chrome://extensions/shortcuts`.
- Optionally install the PaneParcel agent skill from GitHub with `npx skills add lolabradora/paneparcel --skill paneparcel`.

The companion supports Apple Silicon Macs. A supported local session is required for direct delivery. Chrome’s unpacked extension and Web Store extension use separate draft storage.
